
# SOLEMATE - React Shoe Store

A responsive online shoe store built using React and Vite.

## Features

- Display shoe collection
- Filter shoes by category
- Add shoes to cart
- Increase and decrease quantity
- Remove products from cart
- Automatic total price calculation
- Responsive design
- React useState Hook

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following commands:

```bash
npm install
npm run dev
```

5. Open the localhost link shown in the terminal.

## Note

This is a demonstration shopping website. It does not process real payments.
